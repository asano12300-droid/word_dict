# Dictionary App
cliで動く英単語辞典です。

## 使い方
インストール方法
{version}は最新版など使えるバージョンを入れてください
```
curl -O https://raw.githubusercontent.com/asano12300-droid/word_dict/main/storage_deb/{version}/dict_{version}_amd64.deb
```
